# kami-watashi

Solution for sharing notices among family members.

## 総論

### 目的

こどもが学校でもらってくるプリント（通知）を写真で管理し、家族間で共有する。

### 利用イメージ

- 設定
  - 1名が "Googleでログイン" でオーナーとして登録する
  - オーナーが家族のメンバーを招待QRコードで招待する
  - こどもを登録する
- 登録
  - こども（または「家族共通」枠）を選ぶ
  - プリントを写真撮影する、または保存済みの写真を選ぶ（複数ページの場合は複数枚）
  - タイトル・受け取った日・期限または行事の日付・トピックを設定する
- 参照
  - こども一覧からこども（または「家族共通」枠）を選ぶ
  - プリント一覧から写真を見る
  - 必要に応じてトピック・状態で絞り込む

### 提供形態

- Webアプリとして提供する。主な利用環境はスマートフォンのブラウザ（iPhone の Safari、Android の Chrome）とする。
  - ホーム画面に追加して、アプリのように全画面で起動できる（PWA）。
  - 設定画面の「アプリをインストール」から追加する。Android の Chrome ではタップでブラウザのインストール画面を開く。iPhone（Safari にインストールの API がない）とその他のブラウザでは、ブラウザのメニューから追加する手順を表示する。ホーム画面から開いている場合は表示しない。
  - アプリストアでは配信しない。
- 当面は PoC として、告知せずに知人だけで利用する。手ごたえがあれば、決済（Stripe 等）または広告を導入する（未定）。
- 日本向けのサービスとする。日付の判定（今日・週・月の区切り）と日時の表示は、端末の設定にかかわらず JST（Asia/Tokyo）固定とする。

### データの単位

- データは「家族」単位で管理する。こども・プリント・トピック・容量上限はすべて家族に属する。
- 家族のメンバー数には上限がある（オーナーを含む。「リミット値」参照）。
- 1つの Google アカウントがオーナーになれる家族は1つだけとする。
- 1つのブラウザで参加できる家族は1つだけとする（ブラウザに保存する鍵は1つ）。
- オーナーは自分の家族だけに属する。

### 用語

| 用語               | 意味                                                                                                  |
| ------------------ | ----------------------------------------------------------------------------------------------------- |
| 家族               | データを管理する単位。オーナーと招待されたメンバーで構成する                                          |
| メンバー           | 家族に属する人。オーナーと招待されたメンバーの両方を指す                                              |
| オーナー           | Googleログインで家族を作成したメンバー。家族に1人                                                     |
| 招待されたメンバー | オーナーの招待で家族に参加したメンバー                                                                |
| 「家族共通」枠     | 特定のこどもに限らないプリント（家族全体やこども全員に関わるもの）を登録する枠。家族に常に1つ存在する |
| 脱退               | 招待されたメンバーが自ら家族から抜けること                                                            |
| 退会               | オーナーがアプリの利用をやめること                                                                    |

### 権限

| 操作                                                         | オーナー | 招待されたメンバー |
| ------------------------------------------------------------ | -------- | ------------------ |
| メンバーの招待                                               | ○        | ×                  |
| メンバーの削除                                               | ○        | ×                  |
| 脱退                                                         | －       | ○                  |
| 退会                                                         | ○        | －                 |
| 自分の表示名の変更                                           | ○        | ○                  |
| こどもの登録・変更・削除                                     | ○        | ○                  |
| トピックの登録・変更・削除                                   | ○        | ○                  |
| プリントの登録・変更・削除（対応状態の変更、一括削除を含む） | ○        | ○                  |
| 見てねの送信                                                 | ○        | ○                  |
| 履歴・集計の参照                                             | ○        | ○                  |

- 権限は画面とAPIの両方で検証する。

### 共通ルール

- 入力
  - 文字数・件数の上限は「リミット値」参照。上限は画面とAPIの両方でチェックする。文字数は全角・半角とも1文字として数える。
  - こどもの名前・トピック名・表示名は、家族内で一意とする（履歴で区別できるようにするため）。「家族共通」はこどもの名前として予約する。
  - プリントのタイトルは重複を許す。
- 画面
  - 画面上部に、アプリ名（かみわたし）と自分の表示名を常に表示する（ようこそ画面を除く）。
- 日付・日時の表示
  - 年を含める場合は `2026.09.29`（日時は `2026.09.29 10:21`）とする。
  - 年を表示しない場合は `9/29`（曜日付きは `9/29(火)`、日時は `9/29 10:21`）とする。
- 同意
  - 利用規約・プライバシーポリシーへの同意は、使い始めるとき（オーナーは登録時、招待されたメンバーは参加時）に取得する。同意した場合に利用を開始できる。
  - 利用規約・プライバシーポリシーを改定した場合は、次にアプリを開いたときに改めて同意を取得する。
- 削除
  - プリント・トピック・メンバーは、確認ダイアログで確認してから削除する。
  - こどもの削除手順は「こども > 削除」、オーナーの退会の手順は「メンバー > オーナーの退会」参照。
- 同時更新
  - 同じデータを複数のメンバーが同時に変更した場合は、後から保存した変更を有効にする（あと勝ち）。
- オフライン
  - オフライン時は「オフラインです」と表示し、操作を無効にする。
  - プリントの情報・画像はサーバーから取得する。ブラウザの HTTP キャッシュを使う。

### 対象外

次の機能は提供しない。

- アプリストアでのネイティブアプリ（iPhone / Android）の配信
- プッシュ通知・ローカル通知
- 離れて暮らす家族の招待（招待は対面のみ）
- オーナーの交代
- 写真のページ編集（並び替え、1ページだけの削除・追加）
- オフラインでの閲覧（プリントの情報・画像の端末への永続的な保存。PWA の Service Worker によるキャッシュも行わない）
- PDF の取り込み
- オーナーによる別の家族への参加
- 自分自身への見てね
- 容量上限に近づいたときの警告
- 期限リマインダー
- 全こども横断のプリント一覧
- キーワード検索
- データのエクスポート

## 各論

### メンバー

- オーナーが招待QRコードで家族のメンバーを招待し、招待されたメンバーはブラウザに保存した鍵で利用する。
- オーナーはGoogleログインで利用する。

#### 表示名

- オーナーは登録時に入力する（初期値は Google アカウントの名前の先頭から、名前の最大文字数（「リミット値」参照）まで）。
- 招待されたメンバーは、招待QRコードを読み取って参加する時に入力する。
- 自分の表示名は後から変更できる（履歴の扱いは「履歴」参照）。
- 表示名は画面上部の表示（「共通ルール > 画面」参照）、メンバー一覧、見てねの宛先選択、履歴の表示に使う。

#### 招待

- オーナーが画面に表示した招待QRコードを、招待される側が読み取る。招待は対面で行う（招待URLをメッセージなどで送る機能は設けない）。
  - アプリの参加画面（「招待QRコードで参加」）のカメラで読み取る。
  - スマートフォンの標準のカメラで読み取り、開いた招待URLから参加することもできる。
- 招待QRコードには、招待トークンを含む招待URL（`https://<アプリのドメイン>/join?invite=<招待トークン>`）を入れる。どちらの方法で読み取っても、招待URLの招待トークンで参加の手順に進む。参加するブラウザは、招待トークンと引き換えに鍵を取得し、ブラウザに保存する。
- 招待トークンは有効期限（「リミット値」参照）内なら何度でも使える。同じ招待QRコードで複数人が参加できる。
- メンバー数の上限（「リミット値」参照）は次の2回判定し、上限に達している場合はエラーを表示する。
  - 招待QRコードの表示時
  - 招待QRコードを読み取って参加する時（招待トークンと鍵の引き換え時）

#### 認証

- オーナー: Googleログインによるセッション。有効期限は「リミット値」参照。アプリを開くたびに延長する。
- 招待されたメンバー: 参加時にブラウザへ保存した鍵。
  - 鍵はサーバーが生成したランダムな秘密の値とする。
  - サーバーには鍵のハッシュだけを保存する。
  - 鍵は、メンバーの削除・脱退、またはオーナーの退会で無効になるまで使える。
- オーナーのセッションと招待されたメンバーの鍵は、API が発行する Cookie（HttpOnly・Secure）でブラウザに保存する。画面の JavaScript からは読み書きしない。
  - Cookie をファーストパーティとして扱わせるため、画面と API は同じオリジンで配信する（「アーキテクチャ」参照）。
  - Cookie で認証するため、API はクロスサイトリクエストフォージェリ（CSRF）を防ぐ（許可したオリジン以外からの状態を変える要求を拒否する）。

#### 削除・脱退

- 削除・脱退したメンバーについて、次のデータを削除する。
  - そのメンバー本人の既読状態・見てね状態
  - そのメンバーが他のメンバーに送った見てね（受け取った側の見てね状態を「なし」に戻し、既読状態は残す）

#### 再登録

- 機種変更やブラウザのデータ削除、別のブラウザの利用で鍵が失われた場合、オーナーが古いメンバーを削除してから再招待し、メンバーは新しいメンバーとして再登録する。
- オーナーはGoogleログインで復帰する。

#### オーナーの退会

- オーナーが退会すると、その場で家族のデータ（D1 の家族に属するすべての行と、R2 の画像）をすべて削除する。招待されたメンバーの鍵は無効になる。
- 間違えて退会することを防ぐため、2回確認する。1回目は確認ダイアログ、2回目は「退会する」と入力させ、一致した場合に退会する。
- オーナーが Google アカウントを失うと家族のデータを使えなくなることを、ヘルプと利用規約に記載する。

### こども

- こどもは複数登録でき（上限は「リミット値」参照）、プリントはこども（または「家族共通」枠）ごとに管理する。

#### 登録・変更

- こどもの名前は変更できる。
- こども一覧では、各こども（および「家族共通」枠）ごとに次を表示する。
  - 今週（「集計」の週の定義に従う）登録されたプリントの件数
  - 見てねのバッジ（「見てね」参照）

#### 削除

- こどもを削除すると、そのこどものプリント（R2 の画像を含む）も削除する。
- 間違えて削除することを防ぐため、2回確認する。1回目は確認ダイアログ、2回目はこどもの名前を入力させ、一致した場合に削除する。
- 履歴は「こどもの削除」1件にまとめ、削除したプリントの件数を添える。

### プリント

- プリントは写真と付帯情報（タイトル・日付・トピック）で構成し、家族全員で状態を共有する。

#### 項目

| 項目                 | 備考                                                                                                            |
| -------------------- | --------------------------------------------------------------------------------------------------------------- |
| こども               | 必須。こども、または「家族共通」枠。変更で付け替えできる（「こどもの付け替え」参照）                            |
| 写真                 | 1枚以上。複数ページの場合は複数枚を登録できる（上限は「リミット値」参照。取り込み方法は「写真の取り込み」参照） |
| タイトル             | 任意                                                                                                            |
| 受け取った日         | 任意                                                                                                            |
| 期限または行事の日付 | 任意                                                                                                            |
| トピック             | 任意。トピックマスタから選択。複数設定可（上限は「リミット値」参照）                                            |
| 対応状態             | 登録時にも設定できる（「状態」参照）                                                                            |
| 登録日時             |                                                                                                                 |

#### 状態

| 状態       | 値                                   | 単位     |
| ---------- | ------------------------------------ | -------- |
| 既読状態   | 未読 / 既読                          | 個人     |
| 対応状態   | 不要（デフォルト） / 未対応 / 対応済 | 家族共有 |
| 見てね状態 | なし（デフォルト） / 見てね / 見たよ | 個人     |

- 既読状態が既読になるのは、次の2つの場合だけとする。プリントの変更を知らせる場合は見てねを使う。
  - プリント詳細を開いたとき
  - 自分でプリントを登録したとき

#### 詳細画面

- 表示する内容
  - プリント番号（例: 「はなこのプリント（00001）」）
  - タイトル（設定されている場合）
  - 見てね
    - 自分がリクエストした見てね: 送信先ごとの見てね状態（見てね / 見たよ）
    - 自分がリクエストされた見てね: 送信者と見てね状態（見てね / 見たよ）
  - 対応状態（「不要」の場合は目立たない表示にする）
  - 写真
- 操作
  - 写真の拡大（ピンチズーム）
  - ページ送り
  - 見てねの送信（見てね状態アイコンから）
  - 対応状態の変更（対応状態アイコンから）
  - 受け取った日・期限または行事の日付・トピックの表示（情報アイコンから）
  - プリントの変更・削除（アクションボタンから）

#### 一覧

- 並び順は「登録日時順」と「期限順」を切り替えられる。
  - 登録日時順: 登録日時が新しい順。すべてのプリントを表示する。
  - 期限順: 期限（期限または行事の日付）が古い順。期限が設定されたプリントを表示する。期限が過去（今日より前）のプリントは、対応状態が「未対応」の場合に表示する。
- トピック・既読状態・対応状態・見てね状態で絞り込みできる。
  - トピックを複数選んだ場合は、選んだトピックをすべて含むプリントに絞り込む（AND）。

#### 変更・削除

- プリントの変更にはトピックの変更、写真の撮り直しを含む。
- 写真を変更する場合は、すべてのページを撮り直す。

#### こどもの付け替え

- 間違って別のこどもに登録した場合に備え、プリントのこどもを付け替えられる（「家族共通」枠との間も含む）。
- 付け替え後のこどもで新しい連番を採番する（「プリントの連番」参照）。
- 履歴上は、元のこどものプリントの削除と、付け替え後のこどものプリントの登録として扱う。
- 登録日時・写真・既読状態・見てね状態は引き継ぐ。

### 写真と容量

- 写真はアップロード前にブラウザで縮小・圧縮し、家族ごとの容量上限の範囲で保存する。

#### 写真の取り込み

- 写真は次のどちらかで取り込む。撮り直しも同じ方法で行う。
  - スマートフォンのカメラで撮影する（ブラウザのファイル選択からカメラを起動する）
  - 端末に保存された写真から選ぶ
- 取り込んだ写真は、保存する前（登録時・撮り直し時）に1枚ずつ時計回りに90°ずつ回転できる。回転は取り込んだときの写真から行い、何度回転しても画質が落ちないようにする。

#### 写真最適化

- 長辺が上限を超える写真だけを、上限に収まるよう縮小する。
- WebP形式に変換して保存する（同じ見た目ならJPEGより小さいため）。変換時に EXIF（撮影場所の位置情報など）を削除する。
  - ブラウザがWebPに変換できない場合（Safari）は、アプリに同梱したWebPエンコーダ（WebAssembly）で変換する。
  - WebPに切り替える前に保存したJPEGの写真は、そのまま表示する。
- 長辺の上限と画質は「リミット値」参照。

#### 容量

- 容量上限は「リミット値」参照。
- 写真の登録時は、登録後の合計サイズで判定する。上限を超える場合は、そのプリントの登録全体をエラーにする。
- 写真の撮り直し時は、古い写真を除いた撮り直し後の合計サイズで判定する。上限を超える場合は撮り直しをエラーにし、元の写真を残す。
- 上限に達した場合は、オーナー・メンバーが古いプリントを削除して容量を空ける（「古いプリントの一括削除」参照）。

#### 古いプリントの一括削除

- 登録日時が一定期間以上前のプリントを、家族全体（すべてのこどもと「家族共通」枠）から一括削除できる。期間の選択肢は「リミット値」参照。
- 削除前に、削除するプリントの件数を確認ダイアログで表示する。
- 履歴は「一括削除」1件にまとめ、選んだ期間と削除したプリントの件数を添える。

### トピック

- トピックは家族で共有するマスタで、プリントの分類と絞り込みに使う。登録数の上限は「リミット値」参照。

#### 詳細

- 自由入力で登録する。
- トピック名は変更できる。
- トピックを削除すると、すべてのプリントからそのトピックが外れる。

### 見てね

- 「このプリント見てね」を家族のメンバーに送り、相手が見たかどうかを確認できる。
- アプリ内の表示（バッジと絞り込み）で知らせる。

#### 送信

- プリント詳細画面の見てね状態アイコンから送信する。
- 送信者は、自分以外のメンバーから送信先を選べる。
- 送信先のメンバーの見てね状態は「見てね」になる。すでに見てね状態がある場合は、後から送った見てねで上書きする（送信者を更新し、状態を「見てね」に戻す）。

#### 受信

- こども一覧では、各こども（および「家族共通」枠）ごとに、自分の見てね状態が「見てね」のプリントの件数をバッジで表示する。
- バッジをタップすると、そのこどものプリント一覧を見てね状態「見てね」で絞り込んで表示する。
- 見てねの件数は、アプリを開いた時と、アプリの画面（タブ）に戻った時に取得する。

#### 見たよ

- 送信先のメンバーがプリント詳細画面を開いたとき、見てね状態が「見てね」なら「見たよ」にする。
- 送信者は、プリント詳細画面で送信先ごとの見てね状態を確認できる。

### 履歴

- 家族のデータに対する操作を記録し、履歴画面で確認できる。

#### 記録する操作

- こども・トピック・プリントの登録・変更・削除
  - プリントの対応状態の変更は、プリントの変更として記録する。
- 古いプリントの一括削除
- メンバーの参加・離脱・削除（オーナーによる削除）・表示名の変更

#### 表示

- 削除済みの対象の履歴も表示する。
- 名前は操作時点のものを表示する。
- 履歴は無期限に保存する。
- 履歴画面では新しい順に表示し、一定件数ずつ読み込む（件数は「リミット値」参照）。
- 「家族共通」枠のプリントは「家族共通のプリント（00001）」と表示する。

#### 表示例

| 対象     | 操作         | 表示例                                                                                                             |
| -------- | ------------ | ------------------------------------------------------------------------------------------------------------------ |

#### プリントの項目の表示形式

- 登録履歴には、設定した項目を表示する。
- 変更履歴には、変更した項目の変更後の値を表示する。
- 表示形式（表示順）:

| 項目                 | 表示形式                              | 表示する場合                                             |
| -------------------- | ------------------------------------- | -------------------------------------------------------- |
| タイトル             | 「運動会のお知らせ」                  | 設定・変更した場合                                       |
| トピック             | [ サッカークラブ, 試合 ]              | 設定・変更した場合                                       |
| 受け取った日         | 2026.09.25受取                        | 設定・変更した場合                                       |
| 期限または行事の日付 | 2026.10.03まで                        | 設定・変更した場合                                       |
| 対応状態             | 対応=不要 / 対応=未対応 / 対応=対応済 | 登録時は「未対応」「対応済」の場合。変更時は変更した場合 |
| 写真                 | 写真=3枚（撮り直し後の枚数）          | 撮り直した場合                                           |

### 集計

- 登録数の増減と容量使用率をグラフで表示する。

#### 詳細

- 週ごと・月ごとの登録数を、こどもごと（「家族共通」枠を含む）にグラフで表示する。
  - 登録数は、現在登録されているプリントを登録日時で数える（削除済みのプリントは数えない）。
  - 週は暦週（月曜始まり）、月は暦月（各月1日始まり）で区切る。
  - 表示する期間数は「リミット値」参照（直近の期間から数える。今週・今月を含む）。
- 家族全体の容量使用率（使用量 ÷ 容量上限）をグラフで表示する。

### データ保持・プライバシー

- 使われなくなった家族のデータは自動削除し、画像は家族のメンバーだけが参照できるようにする。

#### 詳細

- 一定期間データの参照がない家族のデータは自動削除する（期間は「リミット値」参照）。
  - 「データの参照」は、家族のいずれかのメンバーがアプリを開いたことを指す。
- 画像へのアクセスは Workers の認証ガードで制御し、家族のメンバーだけが参照できる。
- オーナーの退会時・自動削除時のデータ削除についてプライバシーポリシーに記載し、公開する。

### アーキテクチャ

- backend(API)
  - Hono on Cloudflare Workers
  - 画像: Cloudflare R2
  - メタデータ: Cloudflare D1
- frontend
  - Vue3 + Vuetify4 の Webアプリ（SPA）。PWA としてホーム画面に追加できる（Web App Manifest。Service Worker は使わない）
- 配信
  - 画面と API を1つの Cloudflare Worker から同じオリジンで配信する。画面は Worker の静的アセット、API は `/api` 配下。認証の Cookie をファーストパーティとして扱わせるため（`*.workers.dev` はサブドメインごとに別サイト扱いになるので、画面と API を別の Worker にすると Cookie を使えない）。
  - PoC 中は `*.workers.dev` のドメインで配信する。
- 認証
  - Googleログインは Google Identity Services（Webのログインボタン）で ID トークンを取得し、API で検証する。

#### プリントの連番

- 連番はこども（または「家族共通」枠）ごとに 1 から採番する。
- 採番時は `children.last_print_seq`（「家族共通」枠は `families.last_print_seq`）を 1 増やし、その値を `prints.seq` に設定する。
- 連番は一度使った番号を欠番にする（削除済みのプリントと同じ番号が履歴に並ぶことを防ぐため）。
- こどもを付け替えた場合も、付け替え後のこどもで同じ方法で採番する（`last_print_seq` は削除済みを含めた最大値なので、「最大値 + 1」になる）。
- ゼロ埋め（`00001`）は表示時に行い、DBには数値で保持する。

#### R2（画像）

- オブジェクトキー: `{family_id}/{print_id}/{print_image_id}`
- 写真の形式（`image/webp`、切り替え前の写真は `image/jpeg`）はオブジェクトの Content-Type に保持し、配信時にそのまま返す。
- 写真を撮り直した場合は新しい `print_images` 行と新しいキーで保存し、古いオブジェクトを削除する（同じキーの上書きによるキャッシュの不整合を避けるため）。
- 家族のデータ削除時はプレフィックス `{family_id}/` で一括削除する。

#### DBの外で管理するデータ

- **招待トークン:** 有効期限（「リミット値」参照）付きの署名済みトークンとして招待URL（招待QRコード）に含める。
- **オーナーのセッション:** 署名済みトークン（有効期限は「リミット値」参照）で管理する。
- **容量使用量・登録件数:** 容量使用量は `print_images.size` の合計、登録件数は `prints` から都度集計する。
