KAMI-WATASHI / SCREEN DESIGN v1

かみわたし 画面設計

仕様書（総論・各論・リミット値）から画面を洗い出し、iPhone / Android 共通のモバイル画面として設計しました。デザインシステムが空だったため、「紙のプリント」を主題にした生成り×墨×朱のトーンを仮置きしています。Vuetify のコンポーネント（App bar / Bottom navigation / Bottom sheet / Dialog / Chip）に素直に置き換えられる構成です。

ナビゲーション
下部タブ4つ：こども（ホーム）／履歴／集計／設定。プリント一覧・詳細・登録はこども配下にプッシュ遷移。見てね送信・対応状態・情報・絞り込みはボトムシート。削除系はすべてダイアログ確認。
仮定
・日付表示は JST、形式は仕様の履歴例に合わせ 2026.09.27
・画面例のログインユーザーは「一郎（オーナー）」
・プッシュ通知なし＝バッジと絞り込みが唯一の通知導線
・オフライン時は全画面で操作を無効化（7a）
