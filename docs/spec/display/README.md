# 画面設計（Claude Design）

`design.html` は、Claude Design で作った画面設計のアーティファクトから、画面のマークアップ・スタイル・サンプルデータを取り出したもの。

- 元のアーティファクト: https://claude.ai/artifact/TVNGYhmAWCW1o12oHcFMmk （取り出した版: `1790573357-2626`、2026-09-28）
- 取り出したもの: `<x-dc>` 内の画面マークアップ（`{{ }}` / `<sc-for>` / `<sc-if>` はデザインツールのテンプレート記法）と、末尾の `<script type="text/x-dc">`（サンプルデータ）。
- 除いたもの: 埋め込みフォント（Zen Kaku Gothic New / IBM Plex Mono / Material Symbols Rounded）、描画用ランタイム、React。ブラウザで開いてもフォント・アイコンは代替表示になり、テンプレート記法はそのまま見える。読むためのファイルで、見た目の確認は元のアーティファクトで行う。
- 元のアーティファクトを更新した場合は、取り出し直してこのファイルを置き換える。
